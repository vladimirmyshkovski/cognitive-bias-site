## Как читать

- **ID** — постоянный идентификатор, не переиспользуется.
- **Статус**: `open` / `fixed` / `deferred` / `not-a-bug`.
- **Репозиторий**: `site` = `cognitive-bias-site`, `content` = `cognitive-bias-encyclopedia`.

## Известные ограничения (не дефекты)

- **Один экземпляр Pagefind UI на страницу.** На `/search/` модалка из
  Navbar не рендерится — иначе Pagefind откажется инициализировать второй
  экземпляр. Кнопка «Поиск» и ⌘K на этой странице фокусируют её поле.
- **`en/`** — см. ISSUE-09.
