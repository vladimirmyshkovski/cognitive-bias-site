## Известные ограничения (не дефекты)

- **Рендерер markdown** (`src/lib/markdown.ts`) — самописный, на регулярках. Не
  поддерживает таблицы, вложенные списки, изображения, `~~зачёркнутый~~`.
  Это осознанный выбор: контент использует фиксированный подмножество markdown,
  а кастомный рендерер нужен для `[[wiki-links]]`. Плана на замену нет.
- **`Date` в записях** — проставляется пачками при редактировании (41 из 61
  записей имеют `2026-07-05`, 20 — `2026-06-17`). Поле по контракту означает
  «дата создания записи», но фактически это дата массового редактирования.
  Список «Последние добавленные» сортируется по этому полю, поэтому при
  равенстве дат порядок определяется алфавитом. Точность дат — задача
  контента, не сайта.
